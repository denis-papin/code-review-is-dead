# Query project specifications

Use read-only inspection. Locate the specification referenced by the user or follow links from project documentation. Search the project’s actual specifications, public contracts and acceptance scenarios using the terms in the question, including feature or bug identifiers when present.

Read matching passages in context and check their status. Distinguish a proposal from approved behavior. If two sources disagree, report the difference and cite both. If the documents leave a question open, identify the gap without inferring a rule from implementation.

Answer in plain language with the conditions, exceptions and outcomes relevant to the question. Cite the specific file or section and its identifier when one exists. Include implementation details only when the question calls for them.
