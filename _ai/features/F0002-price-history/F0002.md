# F0002 · One month of daily price history

**Status:** Implemented and verified against the integration-test specification.

After finding a gainer, a caller wants to see how its price changed over the past month. A session percentage alone cannot show that history. The caller can also supply a symbol directly to `GET /v1/history/{symbol}`.

## Rules

1. Validate the decoded symbol against `^[A-Za-z0-9^][A-Za-z0-9.^=-]{0,19}$`. Return 400 for invalid syntax before making a provider request. Uppercase a valid symbol and request Yahoo chart data with `range=1mo` and `interval=1d`. Cases H1 and H4.
2. Return the normalized symbol, provider currency and samples in ascending timestamp order. Pair each provider timestamp with the **unadjusted close at the same index**, then omit pairs with a null close. Report timestamps in UTC. The current day’s bar can change during trading. Case H2.
3. For a known symbol, paired empty arrays or entirely null closes yield 200 and an empty samples list. An explicit provider unknown-symbol result yields 404. Cases H3 and H5.
4. Missing currency, missing arrays, unequal array lengths and other unusable responses yield 502. A provider rate limit or timeout yields 503. Cases H6, E1 and E2.
5. Accept a symbol returned by F0001 under the same rules as a direct lookup. Case F1.

For example, a request for `abc` whose only non-null daily close was 101 USD can return:

```json
{"symbol":"ABC","currency":"USD","samples":[{"at":"2026-11-02T14:30:00Z","close":101}]}
```

The [OpenAPI contract](../../openapi.json) defines the response schemas. The [integration-test specification](integration_test_F0002.md) defines the fixtures and assertions.
