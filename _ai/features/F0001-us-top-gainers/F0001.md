# F0001 · US top gainers

**Status:** Implemented and verified against the integration-test specification.

A caller wants to find the strongest gainers in Yahoo’s US Day Gainers screener and select a symbol to investigate. The earlier quote lookup required the caller to know the symbol first. This feature adds discovery through `GET /v1/markets/us/top-gainers`, with no required parameters.

## Rules

1. Request the first page of Yahoo’s US Day Gainers screener with a count of five. Yahoo defines the eligible equities. Rank the returned rows by descending unrounded regular-session percentage change relative to the previous close. Keep provider order when values tie. Return at most five rows. Cases G1 and G2.
2. For each row, return its symbol, percentage and provider market timestamp in UTC. A value of 5 means five percent. A session in progress can change. After the market closes, the timestamp still identifies the reported trade. Case G3.
3. Return 200 for a valid snapshot, including a short page or an empty list. Case G4 covers the empty boundary.
4. Return 502 for an unusable snapshot, including a missing quotes list, duplicate symbol, missing required field, or nonpositive gain. A malformed row invalidates the snapshot. Return 503 for a provider rate limit or timeout, and 502 for other provider failures. Cases G5, E1 and E2.
5. A returned symbol can be used directly as the input to F0002. Case F1.

For example, if Friday’s only qualifying row is BRK-B with a 5.25% gain, a Saturday request can return:

```json
{"gainers":[{"symbol":"BRK-B","changePercent":5.25,"asOf":"2026-11-06T21:00:00Z"}]}
```

The [OpenAPI contract](../../openapi.json) defines the response schemas. The [integration-test specification](integration_test_F0001.md) defines the fixtures and assertions.
